# Icon Button

Icon Button's usage guidance is its Storybook Docs page (Components / Actions / Icon Button),
written in [`icon-button.mdx`](../../../../packages/ui/src/components/atoms/icon-button/icon-button.mdx):
when to use it, anatomy, variants, behavior, do and don't, accessibility, API, and design tokens.
The API table and the tokens there are generated from the code, so they can't drift.

For implementation detail, see [`icon-button-spec.md`](icon-button-spec.md); for the
machine-readable contract, [`icon-button.contract.json`](icon-button.contract.json).
