# Progress Bar

Progress Bar's usage guidance is its Storybook Docs page (Components / Feedback / Progress Bar),
written in [`progress-bar.mdx`](../../../../packages/ui/src/components/atoms/progress-bar/progress-bar.mdx):
when to use it, anatomy, variants, behavior, do and don't, accessibility, API, and design tokens.
The API table and the tokens there are generated from the code, so they can't drift.

For implementation detail, see [`progress-bar-spec.md`](progress-bar-spec.md); for the
machine-readable contract, [`progress-bar.contract.json`](progress-bar.contract.json).
