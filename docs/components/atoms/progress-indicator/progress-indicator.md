# Progress Indicator

Progress Indicator's usage guidance is its Storybook Docs page (Components / Navigation / Progress
Indicator), written in
[`progress-indicator.mdx`](../../../../packages/ui/src/components/atoms/progress-indicator/progress-indicator.mdx):
when to use it, anatomy, variants, behavior, do and don't, accessibility, API, and design tokens.
The API table and the tokens there are generated from the code, so they can't drift.

For implementation detail, see [`progress-indicator-spec.md`](progress-indicator-spec.md); for the
machine-readable contract, [`progress-indicator.contract.json`](progress-indicator.contract.json).
