# Radio

Radio's usage guidance is its Storybook Docs page (Components / Forms / Radio), written in
[`radio.mdx`](../../../../packages/ui/src/components/atoms/radio/radio.mdx): when to use it, anatomy,
behavior, do and don't, accessibility, API (Radio and Radio Group), and design tokens. The API
tables and the tokens there are generated from the code, so they can't drift.

For implementation detail, see [`radio-spec.md`](radio-spec.md); for the machine-readable contract,
[`radio.contract.json`](radio.contract.json).
