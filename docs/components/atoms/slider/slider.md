# Slider

Slider's usage guidance is its Storybook Docs page (Components / Forms / Slider), written in
[`slider.mdx`](../../../../packages/ui/src/components/atoms/slider/slider.mdx): when to use Slider,
Slider Centered, and Slider Range, anatomy, variants, behavior, do and don't, accessibility, API,
and design tokens. The API tables and the tokens there are generated from the code, so they can't
drift.

For implementation detail, see [`slider-spec.md`](slider-spec.md); for the machine-readable
contract, [`slider.contract.json`](slider.contract.json).
