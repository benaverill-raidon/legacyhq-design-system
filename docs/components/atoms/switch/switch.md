# Switch

Switch's usage guidance is its Storybook Docs page (Components / Forms / Switch), written in
[`switch.mdx`](../../../../packages/ui/src/components/atoms/switch/switch.mdx): when to use it,
anatomy, sizes, behavior (including loading), do and don't, accessibility, API, and design tokens.
The API table and the tokens there are generated from the code, so they can't drift.

For implementation detail, see [`switch-spec.md`](switch-spec.md); for the machine-readable
contract, [`switch.contract.json`](switch.contract.json).
