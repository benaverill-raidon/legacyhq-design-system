# Tag

Tag's usage guidance is its Storybook Docs page (Components / Data Display / Tag), written in
[`tag.mdx`](../../../../packages/ui/src/components/atoms/tag/tag.mdx): when to use it, anatomy,
variants, behavior, do and don't, accessibility, API, and design tokens. The API table and the
tokens there are generated from the code, so they can't drift.

For implementation detail, see [`tag-spec.md`](tag-spec.md); for the machine-readable contract,
[`tag.contract.json`](tag.contract.json).
