# Avatar Group

Avatar Group's usage guidance is its Storybook Docs page (Components / Data Display / Avatar Group),
written in [`avatar-group.mdx`](../../../../packages/ui/src/components/molecules/avatar-group/avatar-group.mdx):
when to use it, anatomy, variants, behavior, do and don't, accessibility, API, and design tokens.
The API table and the tokens there are generated from the code, so they can't drift.

For implementation detail, see [`avatar-group-spec.md`](avatar-group-spec.md); for the
machine-readable contract and the Figma mapping, [`avatar-group.contract.json`](avatar-group.contract.json).
