# Breadcrumbs

Breadcrumbs' usage guidance is its Storybook Docs page (Components / Navigation / Breadcrumbs),
written in
[`breadcrumbs.mdx`](../../../../packages/ui/src/components/molecules/breadcrumbs/breadcrumbs.mdx):
when to use it, anatomy, behavior, do and don't, accessibility, API, and design tokens. The API
table and the tokens there are generated from the code, so they can't drift.

For implementation detail, see [`breadcrumbs-spec.md`](breadcrumbs-spec.md); for the
machine-readable contract, [`breadcrumbs.contract.json`](breadcrumbs.contract.json).
