# Button Group

Button Group's usage guidance is its Storybook Docs page (Components / Actions / Button Group),
written in
[`button-group.mdx`](../../../../packages/ui/src/components/molecules/button-group/button-group.mdx):
when to use it, anatomy, variants, behavior, do and don't, accessibility, API, and design tokens.
The API table and the tokens there are generated from the code, so they can't drift.

For implementation detail, see [`button-group-spec.md`](button-group-spec.md); for the
machine-readable contract, [`button-group.contract.json`](button-group.contract.json).
