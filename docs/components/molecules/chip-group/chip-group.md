# Chip Group

Chip Group's usage guidance is its Storybook Docs page (Components / Forms / Chip Group), written in
[`chip-group.mdx`](../../../../packages/ui/src/components/molecules/chip-group/chip-group.mdx): when
to use it, anatomy, variants, behavior, do and don't, accessibility, API, and design tokens. The API
table and the tokens there are generated from the code, so they can't drift.

For implementation detail, see [`chip-group-spec.md`](chip-group-spec.md); for the machine-readable
contract, [`chip-group.contract.json`](chip-group.contract.json).
