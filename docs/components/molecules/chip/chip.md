# Chip

Chip's usage guidance is its Storybook Docs page (Components / Forms / Chip), written in
[`chip.mdx`](../../../../packages/ui/src/components/molecules/chip/chip.mdx): when to use it,
anatomy, variants, behavior, do and don't, accessibility, API, and design tokens. The tokens there
are generated from the code, so they can't drift. Its props are listed by hand for now: Storybook's
docgen can't read a union of props types, so the generated API table is empty.

For implementation detail, see [`chip-spec.md`](chip-spec.md); for the machine-readable contract,
[`chip.contract.json`](chip.contract.json).
