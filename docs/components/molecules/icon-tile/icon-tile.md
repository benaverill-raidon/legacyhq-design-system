# Icon Tile

Icon Tile's usage guidance is its Storybook Docs page (Components / Data Display / Icon Tile),
written in [`icon-tile.mdx`](../../../../packages/ui/src/components/molecules/icon-tile/icon-tile.mdx):
when to use it, anatomy, variants, do and don't, accessibility, API, and design tokens. The API
table and the tokens there are generated from the code, so they can't drift.

For implementation detail, see [`icon-tile-spec.md`](icon-tile-spec.md); for the machine-readable
contract, [`icon-tile.contract.json`](icon-tile.contract.json).
