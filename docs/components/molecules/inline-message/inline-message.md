# Inline Message

Inline Message's usage guidance is its Storybook Docs page (Components / Feedback / Inline Message),
written in [`inline-message.mdx`](../../../../packages/ui/src/components/molecules/inline-message/inline-message.mdx):
when to use it, anatomy, variants, behavior, do and don't, accessibility, API, and design tokens.
The API table and the tokens there are generated from the code, so they can't drift.

For implementation detail, see [`inline-message-spec.md`](inline-message-spec.md); for the
machine-readable contract, [`inline-message.contract.json`](inline-message.contract.json).
