# Pagination

Pagination's usage guidance is its Storybook Docs page (Components / Navigation / Pagination),
written in
[`pagination.mdx`](../../../../packages/ui/src/components/molecules/pagination/pagination.mdx):
when to use it, anatomy, behavior, do and don't, accessibility, API, and design tokens. The API
table and the tokens there are generated from the code, so they can't drift.

For implementation detail, including the range algorithm, see
[`pagination-spec.md`](pagination-spec.md); for the machine-readable contract,
[`pagination.contract.json`](pagination.contract.json).
