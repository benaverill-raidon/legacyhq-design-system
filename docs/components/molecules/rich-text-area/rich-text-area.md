# Rich Text Area

Rich Text Area's usage guidance is its Storybook Docs page (Components / Forms / Rich Text Area),
written in
[`rich-text-area.mdx`](../../../../packages/ui/src/components/molecules/text-area/rich-text-area.mdx):
when to use it, anatomy, variants, behavior, do and don't, accessibility, API, and design tokens. The
API table and the tokens there are generated from the code, so they can't drift.

For implementation detail, see [`rich-text-area-spec.md`](rich-text-area-spec.md); for the
machine-readable contract, [`rich-text-area.contract.json`](rich-text-area.contract.json).
