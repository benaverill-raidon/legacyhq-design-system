# Skeleton

Skeleton's usage guidance is its Storybook Docs page (Components / Feedback / Skeleton), written in
[`skeleton.mdx`](../../../../packages/ui/src/components/molecules/skeleton/skeleton.mdx): when to
use it, anatomy, variants, behavior, do and don't, accessibility, API, and design tokens. The API
table and the tokens there are generated from the code, so they can't drift.

For implementation detail, see [`skeleton-spec.md`](skeleton-spec.md); for the machine-readable
contract, [`skeleton.contract.json`](skeleton.contract.json).
