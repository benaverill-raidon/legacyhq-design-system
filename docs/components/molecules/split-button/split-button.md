# Split Button

Split Button's usage guidance is its Storybook Docs page (Components / Actions / Split Button),
written in
[`split-button.mdx`](../../../../packages/ui/src/components/molecules/split-button/split-button.mdx):
when to use it, anatomy, variants, behavior, do and don't, accessibility, API, and design tokens.
The API table and the tokens there are generated from the code, so they can't drift.

For implementation detail, see [`split-button-spec.md`](split-button-spec.md); for the
machine-readable contract, [`split-button.contract.json`](split-button.contract.json).
