# Tag Group

Tag Group's usage guidance is its Storybook Docs page (Components / Data Display / Tag Group),
written in [`tag-group.mdx`](../../../../packages/ui/src/components/molecules/tag-group/tag-group.mdx):
when to use it, anatomy, variants, behavior, do and don't, accessibility, API, and design tokens.
The API table and the tokens there are generated from the code, so they can't drift.

For implementation detail, see [`tag-group-spec.md`](tag-group-spec.md); for the machine-readable
contract, the tier exception, and the Figma mapping, [`tag-group.contract.json`](tag-group.contract.json).
