# Text Area

Text Area's usage guidance is its Storybook Docs page (Components / Forms / Text Area), written in
[`text-area.mdx`](../../../../packages/ui/src/components/molecules/text-area/text-area.mdx): when to
use it, anatomy, variants, behavior, do and don't, accessibility, API, and design tokens. The API
table and the tokens there are generated from the code, so they can't drift.

For implementation detail, see [`text-area-spec.md`](text-area-spec.md); for the machine-readable
contract, [`text-area.contract.json`](text-area.contract.json).
