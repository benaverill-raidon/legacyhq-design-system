# Text Field

Text Field's usage guidance is its Storybook Docs page (Components / Forms / Text Field), written in
[`text-field.mdx`](../../../../packages/ui/src/components/molecules/text-field/text-field.mdx): when
to use it, anatomy, variants, behavior, do and don't, accessibility, API, and design tokens. The API
table and the tokens there are generated from the code, so they can't drift.

For implementation detail, see [`text-field-spec.md`](text-field-spec.md); for the machine-readable
contract, [`text-field.contract.json`](text-field.contract.json).
