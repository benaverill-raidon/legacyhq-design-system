# Card

Card's usage guidance is its Storybook Docs page (Components / Data Display / Card), written in
[`card.mdx`](../../../../packages/ui/src/components/organisms/card/card.mdx): when to use it,
anatomy, variants, behavior, do and don't, accessibility, API, and design tokens. The API table and
the tokens there are generated from the code, so they can't drift.

For implementation detail, see [`card-spec.md`](card-spec.md); for the machine-readable contract,
[`card.contract.json`](card.contract.json).
