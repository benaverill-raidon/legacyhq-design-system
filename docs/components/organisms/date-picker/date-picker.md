# Date Picker

Date Picker's usage guidance is its Storybook Docs page (Components / Forms / Date Picker), written in
[`date-picker.mdx`](../../../../packages/ui/src/components/organisms/date-picker/date-picker.mdx): when to use it,
anatomy, behavior, do and don't, accessibility, API, and design tokens. The API table and the tokens
there are generated from the code, so they can't drift.

For implementation detail, see [`date-picker-spec.md`](date-picker-spec.md); for the machine-readable contract,
[`date-picker.contract.json`](date-picker.contract.json).
