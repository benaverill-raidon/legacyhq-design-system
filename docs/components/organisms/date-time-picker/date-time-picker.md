# Date Time Picker

Date Time Picker's usage guidance is its Storybook Docs page (Components / Forms / Date Time Picker), written in
[`date-time-picker.mdx`](../../../../packages/ui/src/components/organisms/date-time-picker/date-time-picker.mdx): when to use it,
anatomy, behavior, do and don't, accessibility, API, and design tokens. The API table and the tokens
there are generated from the code, so they can't drift.

For implementation detail, see [`date-time-picker-spec.md`](date-time-picker-spec.md); for the machine-readable contract,
[`date-time-picker.contract.json`](date-time-picker.contract.json).
