# Dropdown Menu

Dropdown Menu's usage guidance is its Storybook Docs page (Components / Actions / Dropdown Menu),
written in
[`dropdown-menu.mdx`](../../../../packages/ui/src/components/organisms/dropdown-menu/dropdown-menu.mdx):
when to use it, anatomy, variants, behavior, do and don't, accessibility, API, and design tokens.
The API table and the tokens there are generated from the code, so they can't drift.

For implementation detail, see [`dropdown-menu-spec.md`](dropdown-menu-spec.md); for the
machine-readable contract, [`dropdown-menu.contract.json`](dropdown-menu.contract.json).
