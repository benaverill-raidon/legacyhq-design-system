# Empty State

Empty State's usage guidance is its Storybook Docs page (Components / Feedback / Empty State),
written in [`empty-state.mdx`](../../../../packages/ui/src/components/organisms/empty-state/empty-state.mdx):
when to use it, anatomy, variants, behavior, do and don't, accessibility, API, and design tokens.
The API table and the tokens there are generated from the code, so they can't drift.

For implementation detail, see [`empty-state-spec.md`](empty-state-spec.md); for the
machine-readable contract, [`empty-state.contract.json`](empty-state.contract.json).
