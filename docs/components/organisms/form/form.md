# Form

Form's usage guidance is its Storybook Docs page (Components / Forms / Form), written in
[`form.mdx`](../../../../packages/ui/src/components/organisms/form/form.mdx): when to use it,
anatomy, behavior, do and don't, accessibility, API, and design tokens. The API table and the tokens
there are generated from the code, so they can't drift.

For implementation detail, see [`form-spec.md`](form-spec.md); for the machine-readable contract,
[`form.contract.json`](form.contract.json).
