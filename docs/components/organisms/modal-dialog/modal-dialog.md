# Modal Dialog

Modal Dialog's usage guidance is its Storybook Docs page (Components / Overlays / Modal Dialog),
written in [`modal-dialog.mdx`](../../../../packages/ui/src/components/organisms/modal-dialog/modal-dialog.mdx):
when to use it, anatomy, variants, behavior, do and don't, accessibility, API, and design tokens. The
API table and the tokens there are generated from the code, so they can't drift.

For implementation detail, see [`modal-dialog-spec.md`](modal-dialog-spec.md); for the
machine-readable contract, [`modal-dialog.contract.json`](modal-dialog.contract.json).
