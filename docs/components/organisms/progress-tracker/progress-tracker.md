# Progress Tracker

Progress Tracker's usage guidance is its Storybook Docs page (Components / Navigation / Progress
Tracker), written in
[`progress-tracker.mdx`](../../../../packages/ui/src/components/organisms/progress-tracker/progress-tracker.mdx):
when to use it, anatomy, variants, behavior, do and don't, accessibility, API, and design tokens.
The API table and the tokens there are generated from the code, so they can't drift.

For implementation detail, see [`progress-tracker-spec.md`](progress-tracker-spec.md); for the
machine-readable contract, [`progress-tracker.contract.json`](progress-tracker.contract.json).
