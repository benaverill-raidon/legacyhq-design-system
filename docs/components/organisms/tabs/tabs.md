# Tabs

Tabs' usage guidance is its Storybook Docs page (Components / Navigation / Tabs), written in
[`tabs.mdx`](../../../../packages/ui/src/components/organisms/tabs/tabs.mdx): when to use it,
anatomy, variants, behavior, do and don't, accessibility, API (Tabs and Tab Panel), and design
tokens. The API tables and the tokens there are generated from the code, so they can't drift.

For implementation detail, see [`tabs-spec.md`](tabs-spec.md); for the machine-readable contract,
[`tabs.contract.json`](tabs.contract.json).
