# Time Picker

Time Picker's usage guidance is its Storybook Docs page (Components / Forms / Time Picker), written in
[`time-picker.mdx`](../../../../packages/ui/src/components/organisms/time-picker/time-picker.mdx): when to use it,
anatomy, behavior, do and don't, accessibility, API, and design tokens. The API table and the tokens
there are generated from the code, so they can't drift.

For implementation detail, see [`time-picker-spec.md`](time-picker-spec.md); for the machine-readable contract,
[`time-picker.contract.json`](time-picker.contract.json).
