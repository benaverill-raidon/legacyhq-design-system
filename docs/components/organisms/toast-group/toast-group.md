# Toast Group

Toast Group's usage guidance is its Storybook Docs page (Components / Feedback / Toast Group),
written in [`toast-group.mdx`](../../../../packages/ui/src/components/organisms/toast-group/toast-group.mdx):
when to use it, anatomy, behavior (setup, the `toast()` API, updating, stacking, timing, motion),
do and don't, accessibility, API, and design tokens. The API table and the tokens there are generated
from the code, so they can't drift.

For implementation detail, see [`toast-group-spec.md`](toast-group-spec.md); for the
machine-readable contract, [`toast-group.contract.json`](toast-group.contract.json).
