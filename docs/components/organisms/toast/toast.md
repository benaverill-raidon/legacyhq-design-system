# Toast

Toast's usage guidance is its Storybook Docs page (Components / Feedback / Toast), written in
[`toast.mdx`](../../../../packages/ui/src/components/organisms/toast/toast.mdx): when to use it,
anatomy, variants, behavior, do and don't, accessibility, API, and design tokens. The API table and
the tokens there are generated from the code, so they can't drift. Toasts are shown and stacked by
Toast Group; see [`toast-group.md`](../toast-group/toast-group.md).

For implementation detail, see [`toast-spec.md`](toast-spec.md); for the machine-readable contract,
[`toast.contract.json`](toast.contract.json).
