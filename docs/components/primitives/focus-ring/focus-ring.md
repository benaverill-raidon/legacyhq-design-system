# Focus Ring

Focus Ring's usage guidance is its Storybook Docs page (Foundations / Focus Ring), written in
[`focus-ring.mdx`](../../../../packages/ui/src/components/primitives/focus-ring/focus-ring.mdx): when
a component should compose it, anatomy, behavior, do and don't, accessibility, API, and design
tokens. The API table and the tokens there are generated from the code, so they can't drift.

For implementation detail, see [`focus-ring-spec.md`](focus-ring-spec.md); for the machine-readable
contract, [`focus-ring.contract.json`](focus-ring.contract.json).
