# Logo

Logo's usage guidance is its Storybook Docs page (Foundations / Logo), written in
[`logo.mdx`](../../../../packages/ui/src/components/primitives/logo/logo.mdx): when to use it,
anatomy, variants, behavior, do and don't, accessibility, API, and design tokens. The API table and
the tokens there are generated from the code, so they can't drift.

For implementation detail, see [`logo-spec.md`](logo-spec.md); for the machine-readable contract,
[`logo.contract.json`](logo.contract.json).
