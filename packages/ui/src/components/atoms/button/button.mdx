<Section title="Variants">

`prominence` sets how much attention a button draws; `tone` sets what the action means. They're
separate props, but only these pairings are designed:

<CombinationTable
  rowAxis="prominence"
  columnAxis="tone"
  columns={['default', 'brand', 'warning', 'error']}
  supported={contract.supportedCombinations}
/>

`primary` with `default` renders the same brand fill as `primary` with `brand`. Any other pairing is
accepted but renders the prominence's default look, so `tone="warning"` on a secondary button changes
nothing.

`prominence="secondary" tone="error"` is the outlined destructive action. Use it when a destructive
action shouldn't be the loudest control in its group, such as Remove beside a primary Save, and keep
`prominence="primary" tone="error"` for the confirming step of a destructive flow.

<Example of={ButtonStories.Variants} />

<Subsection title="Sizes">

Four control heights, from `xs` (24px) to `lg` (48px), shared with Icon Button, Text Field, and the
other controls so they line up in a row. `lg` also sets the label one type size larger. Icons are the
same size at every button size, and there's no prop to change them.

<Example of={ButtonStories.Sizes} />

</Subsection>

<Subsection title="On dark surfaces">

Set `isInverse` on a button that sits on a dark or bold surface, most often inside a Banner. It drops
the fill, uses the inverse text color, and swaps the dark hover and press overlays for light ones so
the button reads against the background. One inverse look serves every prominence for now. Disabled
flattens it the same way it flattens `tone`.

<Example of={ButtonStories.Inverse} />

</Subsection>

</Section>

<Section title="Behavior">

<Subsection title="Loading">

`isLoading` shows a Spinner centered over the content and ignores clicks. The button keeps its
exact size: the label and icons stay in place, hidden, so nothing around it shifts and the text
doesn't reflow. The label stays the accessible name, and `aria-busy` tells assistive technology the
action is running. Don't also make it look disabled; loading already says "don't click this again."

<Example of={ButtonStories.Content} caption="Content: icon placement, loading, width, and the open state, in context." />

</Subsection>

<Subsection title="Opening a menu or panel">

On a button that opens a menu or panel, set `isExpanded` to whether it's open. It sets
`aria-expanded` and keeps the hover fill while the menu is open, at the button's own width. Leave it
unset on a button that doesn't open anything.

</Subsection>

<Subsection title="Width">

Buttons size to their label. `isFullWidth` fills the container, for a form footer or a mobile action
bar; it's a layout choice for those places, not a default.

</Subsection>

<Subsection title="Focus and hover">

Keyboard focus shows the hover fill together with the shared Focus Ring, so a keyboard user sees both
signals at once. Don't give a button a focus style that looks unrelated to its hover.

<Example of={ButtonStories.States} />

</Subsection>

<Section title="Accessibility">

- Button renders a native `button`, so it's focusable, announced as a button, and activated by Enter
  and Space with no extra code. Don't rebuild it with `role="button"` on another element.
- The visible label is the accessible name. Write it as the action ("Delete matter", not "OK"), and
  don't rely on the error or warning color alone to carry the meaning.
- `type` defaults to `button`, so a Button inside a form submits it only when you ask for `submit`.
- `disabled` is the native attribute: the button leaves the tab order. A loading button stays
  focusable, with `aria-busy` and `aria-disabled`, so focus doesn't jump while the action runs, and
  its label stays its accessible name.
- `isExpanded` sets `aria-expanded` on a button that opens a menu or panel.

<Keyboard>
  <Key keys="Tab">Moves focus to the button. A disabled button is skipped.</Key>
  <Key keys="Enter">Activates the button, unless it's loading.</Key>
  <Key keys="Space">Activates the button, unless it's loading.</Key>
</Keyboard>
