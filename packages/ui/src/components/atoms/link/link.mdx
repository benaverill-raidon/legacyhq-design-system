<Section title="Variants">

`appearance` picks the color for the surface the link sits on, not how loud it is. `default` is the
brand color and `subtle` is the quieter content color, both for light surfaces. `inverse` is for a
dark or bold surface only: on a light one it has almost no contrast.

<Example of={LinkStories.Variants} />

<Subsection title="Sizes">

`md` sets the text in `heading-xs` and `sm` in `heading-xxs`. The new-tab icon follows the size.

<Example of={LinkStories.Sizes} />

</Subsection>

<Subsection title="Emphasis">

`emphasis` sets the weight only. `strong`, the default, is a heading weight for a name or a
first-column identifier, such as a client's name in a table. `default` is the body weight, for any
other link.

<Example of={LinkStories.Emphasis} />

</Subsection>

</Section>

<Section title="Behavior">

<Subsection title="Opening in a new tab">

With `target="_blank"`, Link adds three things on its own: the external-link icon after the text,
visually hidden `newTabLabel` text so assistive technology hears what the icon shows, and
`noopener noreferrer` in `rel`. Any `rel` values you pass are kept, with those two added. Without a
`target`, Link renders `target="_self"`.

<Example of={LinkStories.Content} caption="Inline in a sentence, internal and external targets, and inverse links on a dark surface." />

</Subsection>

<Subsection title="Hover, focus, and visited">

A link has no underline at rest and underlines on hover. There's no pressed style. Keyboard focus
shows the shared Focus Ring, shaped by a small corner radius so it looks the same wherever the link
sits. Visited links turn purple in every appearance, a lighter purple for `inverse`; the color comes
from the browser's history through `:visited`, so it can't be pinned in a story.

<Example of={LinkStories.States} />

</Subsection>

<Subsection title="Long text and no disabled state">

Long link text wraps inside the link instead of truncating, and the new-tab icon wraps with it.
Link is an inline flex box, so in a sentence, a link that doesn't fit the rest of a line moves to
the next line whole rather than breaking partway with the text around it.

Link has no disabled state: if a destination isn't available, show plain text instead of a link.

<Example of={LinkStories.EdgeCases} />

</Subsection>

<Do caption="Let a new-tab link add its own icon and hidden new-tab text." code={`<Link href="https://example.com" target="_blank">

<Section title="Accessibility">

- Link renders a native `a` with an `href`, so it's announced as a link, can be opened in a new tab,
  and shows where it goes. Don't give it `role="button"` or use it for an action.
- The text is the accessible name. With `target="_blank"`, the name ends with `newTabLabel`, so it's
  read as "Court filing guidelines (opens in a new tab)". The icon is hidden from assistive
  technology. Translate `newTabLabel` with the rest of your interface.
- At rest, a link differs from the text around it by color and, with `emphasis="strong"`, by weight.
  It has no underline until hover.
- Focus shows the shared Focus Ring.
- Link has no disabled state, so it never sets `aria-disabled`.

<Keyboard>
  <Key keys="Tab">Moves focus to the link.</Key>
  <Key keys="Enter">Follows the link.</Key>
  <Key keys="Space">Scrolls the page, as on any link. It doesn't follow it.</Key>
</Keyboard>

</Section>
