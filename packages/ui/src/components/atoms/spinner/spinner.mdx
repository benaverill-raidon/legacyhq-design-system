<Section title="When to use">

<Usage>
<UseFor>

- A wait you can't measure in one part of the page: a panel, a table, a card.
- A loading row, beside text that says what's loading.
- A standalone loading state with no text nearby, with `label`.

</UseFor>
<UseInstead>

- **Progress you can measure:** <DocLink to="Components/Feedback/Progress Bar" />.
- **Content loading into a layout you already know:** <DocLink to="Components/Feedback/Skeleton" />, which holds the layout's shape.
- **A button whose action is running:** <DocLink to="Components/Actions/Button" />'s `isLoading`, which shows a Spinner for you and keeps the button's size.

</UseInstead>
</Usage>

</Section>

<Section title="Anatomy">

<Anatomy specimen={<Spinner size="xl" label="Loading matters" />}>
  <Part name="container" target={spinnerStyles.spinner}>The root `span`, sized by `size`. It carries the accessibility attributes.</Part>
  <Part name="indicator" target={spinnerStyles.svg}>An SVG quarter-circle arc in the current text color, which rotates. Always hidden from assistive technology.</Part>
  <Part name="label">Visually hidden text, rendered only when `label` is set.</Part>
</Anatomy>

<Section title="Variants">

Spinner has one look. `size` is its only visual option: 12, 16, 24, or 48px for `sm`, `md`, `lg`,
and `xl`, with `lg` the default. At `xl` the arc is drawn at 32px inside the 48px box. The stroke
gets thicker with size.

<Example of={SpinnerStories.Sizes} />

<Subsection title="Color">

Spinner has no color of its own. The arc is drawn in `currentColor`, so it takes the color of the
text it sits in: a Button's label color, an error message, or plain body text. There's no `tone` or
`color` prop; set the color on the surrounding text.

</Subsection>

</Section>

<Section title="Behavior">

<Subsection title="Decorative or announced">

Without `label`, Spinner is hidden from assistive technology, for a spinner next to visible text
that already says what's loading. With `label`, it becomes a polite status region that holds the
label as visually hidden text, for a spinner that's the only sign of loading.

<Example of={SpinnerStories.Content} caption="Standalone, beside text, inside a loading Button, and in a card." />

</Subsection>

<Subsection title="Motion">

The arc turns continuously with the `spin-loop` motion recipe, one turn every 860ms. With reduced
motion it stops, and the arc stays visible rather than being swapped for something else.

<Example of={SpinnerStories.EdgeCases} caption="Reduced motion, color taken from the surrounding text, and a dark surface." />

</Subsection>

<Subsection title="Inside other components">

Button and Link Button show a `md` Spinner centered over their content while `isLoading`, and Icon
Button shows a `sm` one in place of its icon. Switch, Menu's loading row, and Toast's loading tone
use one too. Use those loading states rather than adding a Spinner yourself.

</Subsection>

</Section>

  <Spinner />
</Dont>
<Do caption="Set isLoading on the button whose action is running." code={`<Button prominence="primary" isLoading>Save matter</Button>`}>
  <Button prominence="primary" isLoading>
    Save matter
  </Button>
</Do>
<Dont
  caption="Swap a Spinner into a button's label, which resizes the button and doesn't mark it busy."
  code={`<Button prominence="primary">
  <Spinner size="md" /> Saving…
</Button>`}
>
  <Button prominence="primary">
    <Spinner size="md" /> Saving…
  </Button>
</Dont>
<Do caption="Use Progress Bar when you can measure how far along the work is." code={`<ProgressBar value={42} label="Uploading client files" />`}>
  <ProgressBar value={42} label="Uploading client files" />
</Do>
<Dont caption="Put a percentage in a spinner's label, where sighted users never see it." code={`<Spinner label="Uploading, 42% complete" />`}>
  <Spinner label="Uploading, 42% complete" />
</Dont>
</Guidelines>

<Section title="Accessibility">

- Spinner renders a `span` holding an SVG arc. The SVG is always `aria-hidden` and not focusable.
- Without `label`, the `span` is `aria-hidden` and has no role. Put it beside visible text that says
  what's loading, or the wait is silent for screen reader users.
- With `label`, the `span` gets `role="status"` and `aria-live="polite"`, and the label is inside it
  as visually hidden text.
- Spinner sets `role`, `aria-live`, and `aria-hidden` itself, so values you pass for them are
  replaced.
- It isn't focusable and has no keyboard interaction.
- Reduced motion stops the rotation. The arc is drawn in the surrounding text color, so it has that
  text's contrast.

</Section>
