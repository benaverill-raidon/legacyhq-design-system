<Section title="Variants">

`tone` picks a color set for the fill, border, and text. `default` is neutral and `brand` is the
product color. The other eight are accent colors with no fixed meaning, for telling kinds of records
apart: Rich Text Area, for one, shows accounts and people in blue, matters in teal, and roadmaps in
purple by default. Don't use them to say whether something is good or bad. They're the same
accent colors as <DocLink to="Components/Data Display/Icon Tile" />'s `tone`, and work the same way.

<Section title="Behavior">

<Subsection title="Display, link, remove, or click">

Tag renders a different root for each job:

- **No `href`, not removable:** a `span` that only displays.
- **`href`:** the whole tag is an `a`. With `target="_blank"` and no `rel`, Tag adds
  `rel="noopener noreferrer"`. A `rel` you pass is used as given.
- **`isRemovable`:** a wrapper `span` holding the content and a separate remove button. The content
  is a link when `href` is set, a button with `onClick` or `isInteractive`, and a `span` otherwise.
- **`isInteractive` or `onClick`, with no `href` and not removable:** a `button`, for a tag that
  opens something, such as Tag Group's overflow tag.

In a removable tag, the content and the remove button are separate controls: `onClick` runs from
the content, and the remove button's click never reaches it.

</Subsection>

<Subsection title="Removing">

The remove button calls `onRemove`. Its click doesn't reach the link, so removing never navigates.
Tag doesn't remove itself: take it out of your list in `onRemove`. It doesn't move focus either, so
decide where focus goes when the tag disappears.

The button's accessible name is `removeLabel`. Without it, Tag uses "Remove" and the text when
`children` is a string, and "Remove tag" when it isn't.

</Subsection>

<Subsection title="Focus, hover, and disabled">

A link and its remove button are separate controls: each takes focus on its own, with its own Focus
Ring at its own edges, and its own hover and pressed fill, which fades in with `fade-quick`. A
display-only tag has no hover or focus look.

`disabled` swaps the fill, border, and text for the disabled colors and turns off hover and press.
A link gets `aria-disabled`, leaves the tab order, and doesn't navigate when clicked. The remove
button and an interactive tag get the native `disabled`.

<Example of={TagStories.States} />

</Subsection>

<Subsection title="Long text">

A tag stays on one line. When its container is narrower than the tag, the text ends with an ellipsis;
there's no tooltip with the full text. Tags in a wrapping row move to the next line as the row fills.

<Section title="Accessibility">

- Tag renders a native element for each job: a `span` to display, an `a` to link, a `button` to
  remove or to click. The remove button is never inside the link, so they're separate controls.
- The text is the accessible name of the link or the interactive tag. The remove button is named by
  `removeLabel`, or "Remove" and the text; translate `removeLabel` with the rest of your interface.
- Icons in `elemBefore` are decorative by default, so the text alone names the tag.
- A disabled link keeps its `href`, sets `aria-disabled`, and leaves the tab order, so screen reader
  users can still find it and hear that it's unavailable. Disabled buttons use the native `disabled`.
  On a display-only tag, `disabled` only changes the look.
- Focus shows the shared Focus Ring on the link, the remove button, or the interactive tag.
- Tag doesn't move focus when it's removed. There's no Delete or Backspace shortcut: tags are removed
  with their button.

<Keyboard>
  <Key keys="Tab">Moves to the link or interactive content, then to its remove button, as separate stops. Display-only and disabled tags are skipped.</Key>
  <Key keys="Enter">Follows the link, or activates the remove button or an interactive tag.</Key>
  <Key keys="Space">Activates the remove button or an interactive tag. On a link it scrolls the page, as on any link.</Key>
</Keyboard>

Any other attribute goes to the root element (in a removable tag, the wrapper `span`), and `className`
is added to its classes. `tabIndex` and `aria-describedby` go to the link or the button when there is
one, and to the root otherwise. `isDisabled` is the deprecated name for `disabled` and still works.
