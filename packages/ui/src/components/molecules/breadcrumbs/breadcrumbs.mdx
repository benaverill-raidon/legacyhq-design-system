<Section title="Behavior">

<Subsection title="The current page">

Whether an item is a link depends only on its `href`. Give every level above the current page an
`href`, and leave it off the current page, the last item: it renders as text marked
`aria-current="page"`, not a link to the page you're on. If the last item has an `href`, it renders
as a link and nothing is marked current. An item in the middle without one renders as current text
too.

<Example of={BreadcrumbsStories.Composition} caption="Two-level and deeper trails, a leading icon, a single item, a custom name, and a trail in a page header." />

</Subsection>

<Subsection title="One color for the whole trail">

Every item uses the subtle content color, the links and the current page alike, so the trail reads
as one quiet line. Links don't turn purple once visited: whether you've opened a page before isn't
something a location trail shows. The links underline on hover and show the shared Focus Ring; the
current page does neither.

</Subsection>

<Subsection title="Icons">

`iconBefore` and `iconAfter` put an icon beside an item's label, such as a home icon on the first
level. Breadcrumbs doesn't size the icon, so pass the size you want, as the story does with `sm`.

</Subsection>

<Subsection title="Long trails">

The trail stays on one line: it doesn't wrap, truncate, or collapse middle levels. Keep labels short
so a deep trail still fits its container.

</Subsection>

</Section>

<Section title="Accessibility">

- The root is a `nav` landmark named by `ariaLabel`, "Breadcrumb" by default. Translate it with the
  rest of your interface. Breadcrumbs takes `ariaLabel`, not `aria-label`, and passes no other
  attributes to the `nav`.
- The levels are an ordered list, so assistive technology announces how many there are.
- Each level above the current page is a Link: announced as a link, in the tab order, with the
  shared Focus Ring.
- The current page is text with `aria-current="page"`, so it's announced as the current page and
  isn't focusable.
- The `/` separators and any icons are hidden from assistive technology.

<Keyboard>
  <Key keys="Tab">Moves focus to the next link in the trail. The current page is skipped.</Key>
  <Key keys="Enter">Follows the focused link.</Key>
</Keyboard>

</Section>

<Section title="API">

<PropsTable of={BreadcrumbsStories} />

<Subsection title="Breadcrumb item">

Each entry in `items` takes:

- `label`, required: the visible text for the level.
- `href`: makes the item a Link. Leave it off the current page.
- `target`: passed to the Link. `_blank` adds Link's new-tab icon and hidden text.
- `onClick`: passed to the Link, so only an item with an `href` calls it.
- `iconBefore` and `iconAfter`: an icon before or after the label, hidden from assistive technology.

</Subsection>
