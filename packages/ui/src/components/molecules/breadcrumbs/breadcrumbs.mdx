# Breadcrumbs

Breadcrumbs are a navigation system used to show a user's location in a site or app - an ordered
trail from a root section down to the current page, letting people jump back to any ancestor in
one step.

<Canvas of={BreadcrumbsStories.Playground} />

## When to use

- Deep or nested sections - multi-level settings, nested folders/categories.
- Anywhere "how did I get here, and how do I go back" is a real question.

## When not to use

- **For a shallow or single-level app.** Breadcrumbs adds hierarchy signal that doesn't exist.
- **For linear flow progress with unvisited future steps.** Use `ProgressIndicator` instead - that's
  progress through a sequence, not a location trail.
- **More than once per page.**

## Anatomy

Breadcrumbs renders a `nav` landmark containing an `ol` of `li` items. A `/` separator precedes
every item except the first. Every item with an `href` renders as the real `Link` atom; the item
without one - always the last - renders as non-interactive text carrying `aria-current="page"`.

## Usage guidance

### The current page isn't a link

The Figma source demo renders all 8 example crumbs identically, as `Link` instances. This component
deliberately diverges from that literal sample: whichever item in `items` has no `href` renders as
plain, non-interactive text instead - matching the WAI-ARIA Breadcrumb Pattern, where the current
page is announced (`aria-current="page"`) but not clickable. In practice, that's always the last
item - omit `href` there and the component takes care of the rest.

<Canvas of={BreadcrumbsStories.Composition} />

### Adding icons

`iconBefore` and `iconAfter` accept any `ReactNode` - typically a small icon from the generated icon
set (`size="sm"` reads well against the trail's text size).

## Do / Don't

**Do** omit `href` on the current (last) item.

```tsx
<Breadcrumbs
  items={[
    { label: 'Settings', href: '/settings' },
    { label: 'Account' },
  ]}
/>
```

**Don't** give every item an href, including the current page.

```tsx
<Breadcrumbs
  items={[
    { label: 'Settings', href: '/settings' },
    { label: 'Account', href: '/settings/account' },
  ]}
/>
```

---

**Do** use Breadcrumbs for a real hierarchy.

```tsx
<Breadcrumbs items={[{ label: 'Docs', href: '/docs' }, { label: 'Components' }]} />
```

**Don't** use Breadcrumbs to show progress through a linear, not-yet-visited flow.

```tsx
{
  /* Use ProgressIndicator instead. */
}
<Breadcrumbs items={[{ label: 'Step 1' }, { label: 'Step 2' }, { label: 'Step 3' }]} />;
```
