<Section title="When to use">

<Usage>
<UseFor>

- A feature or a benefit that needs a small, colored graphic.
- The illustration in an empty state.
- A leading visual in a card or a list row that sorts its content by kind.
- A heading for a group of results, as Rich Text Area's record picker does with its 16px tiles.

</UseFor>
<UseInstead>

- **An action:** <DocLink to="Components/Actions/Icon Button" />. Icon Tile has no click handler and can't take focus.
- **A count:** <DocLink to="Components/Data Display/Badge" />. Icon Tile has no place for text.
- **A record or a category with a name:** <DocLink to="Components/Data Display/Tag" />.
- **A person or a team:** <DocLink to="Components/Data Display/Avatar" />.
- **An icon beside text that needs no emphasis:** the icon on its own, from <DocLink to="Foundations/Icons" />.

</UseInstead>
</Usage>

<Section title="Variants">

<Subsection title="Tone and appearance">

`tone` picks the color: `taupe` for a neutral tile, `brand` for the product color, or one of eight
accent colors. The accent colors have no fixed meaning; use them to tell kinds of things apart, not
to say whether something is good or bad. `appearance` sets how strong the color is: `default` is a
light tint with the icon in the tone's color, and `bold` is a solid fill with an inverse icon. Use
`bold` for the one tile that should stand out, not for every tile in a row.

In Figma, one `tone` property holds both choices (`red`, `redBold`, and so on). Code splits it into
`tone` and `appearance`, as Button splits meaning from emphasis. `gray`, the old name for `taupe`, is
still accepted.

<Example of={IconTileStories.Variants} />

</Subsection>

<Subsection title="Shapes">

`square`, the default, has rounded corners: 4px at `xxs` and `xs`, 8px at `sm` and `md`, and 12px at
`lg`. `round` is a circle; use it beside other round things, such as an Avatar.

<Example of={IconTileStories.Shapes} />

</Subsection>

<Subsection title="Sizes">

Five sizes, from `xxs` (16px) to `lg` (48px), with `md` (40px) the default. The icon is always
two-thirds of the tile, 32px in a 48px tile, so there's no icon size to set. Any icon from the icon
set works as it is: the tile overrides its own size and color.

<Example of={IconTileStories.Sizes} />

</Subsection>

</Section>

<Section title="Do and don't">

<Guidelines>
<Do
  caption="Leave the tile decorative when the text beside it says what it means."
  code={`<IconTile tone="green">
    <TrustIcon />
</IconTile>
<span>Averill Family Living Trust</span>`}
>
  <IconTile tone="green">
    <TrustIcon />
  </IconTile>
  <span>Averill Family Living Trust</span>
</Do>
<Dont
  caption="Label a tile that repeats the text beside it. Screen readers then read the same thing twice."
  code={`<IconTile tone="green" decorative={false} ariaLabel="Trust">
    <TrustIcon />
</IconTile>
<span>Averill Family Living Trust</span>`}
/>
<Do
  caption="Name a tile that stands alone with decorative={false} and ariaLabel."
  code={`<IconTile tone="red" appearance="bold" decorative={false} ariaLabel="Error">
    <CloseIcon />
</IconTile>`}
>
  <IconTile tone="red" appearance="bold" decorative={false} ariaLabel="Error">
    <CloseIcon />
  </IconTile>
</Do>
<Dont
  caption="Set decorative={false} without ariaLabel. The tile becomes an image with no name, and warns in development."
  code={`<IconTile tone="red" appearance="bold" decorative={false}>
    <CloseIcon />
</IconTile>`}
/>
<Do caption="Use Badge for a count." code={`<Badge>3</Badge>`}>
  <Badge>3</Badge>
</Do>
<Dont caption="Put a number in a tile. It's built for one icon, and a decorative tile hides the number from screen readers." code={`<IconTile tone="blue">3</IconTile>`}>
  <IconTile tone="blue">3</IconTile>
</Dont>
</Guidelines>

</Section>

<Section title="Accessibility">

- Icon Tile renders a `div`. It isn't focusable, has no hover or pressed state, and takes no click
  handler, so there's nothing to operate with the keyboard.
- By default it's decorative: the root is `aria-hidden="true"` with no role, so assistive technology
  skips it and the text beside it carries the meaning.
- With `decorative={false}`, the root gets `role="img"` and `aria-label` from `ariaLabel`. Without
  `ariaLabel` it's an image with no name, and Icon Tile warns in the console during development
  (not in production builds).
- The tone's color doesn't carry meaning on its own: pair the tile with text, or name it.
