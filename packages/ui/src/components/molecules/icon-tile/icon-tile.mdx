# Icon Tile

Icon Tile pairs a single icon with a colored, sized background shape. It gives an icon more visual
emphasis than a bare icon or an Icon Button affords - use it where an icon should read as a small
piece of imagery, not as a clickable control.

<Canvas of={IconTileStories.Playground} />

## When to use

- A feature or benefit needs a small, colored icon graphic.
- A list or card needs a leading visual that categorizes its content by color/hue.
- An empty state needs a single colored icon as its illustration.

## When not to use

- **As a clickable control.** Icon Tile has no interactive states and no `onClick` - use
  `IconButton` if the icon needs to respond to input.
- **For a count or short text value.** Use `Badge` or `Tag` - Icon Tile has no text slot.
- **With more than one icon.** Icon Tile centers exactly one icon.

## Anatomy

Icon Tile has two parts: a sized, colored `div` root, and a single icon (`children`) centered
inside it. There is no text slot and no border by default.

## Usage guidance

### Tone vs. appearance

The Figma source models hue and boldness as one flattened 20-value `appearance` property (for
example `red`, `redBold`). This component splits that into two independent props, matching this
system's existing convention of separating visual weight from meaning (see `Button`):

- **`tone`** - the hue/semantic meaning: `gray`, `brand`, or one of eight accent hues.
- **`appearance`** - the visual weight: `default` (a subtle tint) or `bold` (a solid, saturated
  fill with an inverse/white icon).

<Canvas of={IconTileStories.Variants} />

### Choosing a shape

`shape="square"` (the default) is a rounded-square container. `shape="round"` is fully circular -
reach for it when the tile sits next to circular elements like `Avatar`.

<Canvas of={IconTileStories.Shapes} />

### Choosing a size

Icon Tile has five sizes, `xxs` through `lg`. The icon inside is always sized to two-thirds of the
tile - there's no separate icon-size prop to keep in sync.

<Canvas of={IconTileStories.Sizes} />

### Accessible labelling

Icon Tile is `decorative` (aria-hidden) by default, because in most compositions the icon
reinforces meaning that adjacent text already conveys - a feature title, a list label. Set
`decorative={false}` with `ariaLabel` only when the tile is the *only* carrier of that meaning.

<Canvas of={IconTileStories.Composition} />

## Do / Don't

**Do** let adjacent text carry the meaning and leave Icon Tile decorative.

```tsx
<div>
  <IconTile tone="brand">
    <CheckIcon />
  </IconTile>
  <span>Automated backups</span>
</div>
```

**Don't** wrap Icon Tile in a click handler to make it interactive.

```tsx
<IconTile onClick={openDetails}>
  <CheckIcon />
</IconTile>
```

---

**Do** use `decorative={false}` and `ariaLabel` when the tile stands alone.

```tsx
<IconTile decorative={false} ariaLabel="Error">
  <CloseIcon />
</IconTile>
```

**Don't** put text content inside Icon Tile.

```tsx
<IconTile>3</IconTile>
```

## Related components

- **Icon** - the primitive Icon Tile always wraps as `children`.
- **Avatar** - a similarly sized, similarly shaped container, but for a person/entity rather than a
  symbol.
- **Icon Button** - when the icon needs to be a clickable action instead of a static visual.
- **Badge** / **Tag** - for numeric or text content instead of a standalone icon.
