<Section title="Accessibility">

- Key Value List renders a `dl`, and each Key Value Pair inside it a `div` with a `dt` and a `dd`.
  Screen readers can announce it as a list and read each key with its value.
- The `dl` has no name. Name the group with a heading before it when the page has several.
- The list isn't focusable and has no keyboard behavior; the inline controls in its pairs keep their
  own.

</Section>
