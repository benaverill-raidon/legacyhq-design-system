export function StatusSelect({ placeholder, label = 'Matter status', initial = 'in-review', bare = false }) {
  const [value, setValue] = React.useState(initial);
  const select = <Select options={statusOptions} value={value} onChange={setValue} placeholder={placeholder} />;
  return bare ? select : <Field label={label}>{select}</Field>;
}

export function AssigneeSelect() {
  const [value, setValue] = React.useState(['jordan', 'priya']);
  return (
    <Field label="Assignees">
      <Select inputType="multi" options={peopleOptions} value={value} onChange={setValue} placeholder="Add assignees" />
    </Field>
  );
}

<Section title="Variants">

<Subsection title="Single and multi">

`inputType` decides how many values someone can choose, and the props are typed by it: `value` is a
string or `null` for `single`, the default, and an array for `multi`. A single-select field shows
the chosen option's label, after its `icon` if it has one, and its menu rows are radio rows. A multi-select field shows each chosen
value as a select Chip before the input, and its rows are checkbox rows.

<Example of={SelectStories.InputTypes} />

</Subsection>

<Subsection title="Sizes and context">

Three heights: `sm` (32px), `md` (40px), and `lg` (48px), the same as Text Field. Chips are `sm` in
an `sm` or `md` field and `md` in an `lg` one. `context` is Text Field's: `default` is the bordered
field for forms, and `inline` has no border or fill until someone hovers or focuses it, for a field
inside a row. Field passes `context="inline"` when it's inline. `tone` and `appearance` are older
names for `context`, still accepted: `subtle` and `inline` both mean `inline`.

<Example of={SelectStories.Variants} />

</Subsection>

</Section>

<Section title="Behavior">

<Subsection title="Opening and filtering">

A click anywhere on the field opens the menu, and the caret opens or closes it. Typing opens it too,
and filters the options to those whose label contains the text, ignoring case. While the menu is
open, a single-select field's input holds what's typed, with the current choice as its placeholder.
When nothing matches, the menu shows `emptyMessage`, "No matches" by default.

<Example of={SelectStories.Typeahead} caption="Type a name to filter; type something else to see the empty message." />

</Subsection>

<Subsection title="Choosing">

In a single-select field, choosing a row calls `onChange` with its value, closes the menu, and
returns focus to the input.
Choosing the chosen row again keeps it chosen: Select never clears a single value, so offer your
own way to clear one if it's optional. In a multi-select field, choosing a row adds or removes its
value, clears the typed text, and keeps the menu open. A chip's remove button removes its value, and
Backspace in an empty input removes the last one.

</Subsection>

<Subsection title="Groups">

Give options a `group`, and options with the same group in a row are listed under that heading. The
headings are visual only.

<Example of={SelectStories.Grouped} />

</Subsection>

<Subsection title="Your own filtering">

With `onSearchChange`, Select stops filtering and calls it with the typed text, so you can pass the
matching options yourself, such as results from a server. Pass `searchValue` too to control the text.

<CodeSample code={ownFiltering} />

</Subsection>

<Subsection title="States">

`invalid` gives the field Text Field's error border and sets `aria-invalid`; in a Field with
`state="error"`, Field sets it for you. `disabled` disables the input, so the menu can't open, and
disables the chips' remove buttons.

<Example of={SelectStories.States} />

</Subsection>

<Subsection title="Many values">

The field stays one line high. When chips run out of room, they shrink and clip rather than wrap.

<Example of={SelectStories.EdgeCases} caption="Edge cases: every value chosen, a disabled option, and a dark surface." />

</Subsection>

</Section>

<Section title="Accessibility">

- The trigger is a native `input` in Text Field's frame, with `role="combobox"`,
  `aria-haspopup="menu"`, and `aria-autocomplete="list"`. Dropdown Menu sets `aria-expanded`, and
  `aria-controls` pointing at the menu while it's open.
- Name it with Field, which wires its label to the input, or with `aria-label` or
  `aria-labelledby`. The same name is passed to the menu. With only a native `label`, the menu is
  named from that label when it opens: by reference when the label has an `id`, otherwise by its
  text.
- In a Field, the message is added to the input's description, and an error sets `aria-invalid`.
  `required` sets the input's native `required`.
- The menu is a Menu, announced as a menu, added at the end of the page. Rows are `menuitemradio`
  in single-select and `menuitemcheckbox` in multi-select, with `aria-checked` on the chosen ones.
  Group headings aren't announced.
- Opening and typing keep focus in the input. Arrow Down moves focus into the menu's first row.
  A pick, Escape, or Tab from inside the menu returns focus to the input; a single-select pick,
  Escape, and Tab also close the menu. Focus moving anywhere outside the field and its menu closes
  the menu.
- Each chip's remove button is its own tab stop before the input, named "Remove" plus the value.
  `getRemoveLabel` builds that name from the value's label, for a translation.
- The caret is hidden from assistive technology and works only with a pointer; the keys below do
  the same from the input.
- `disabled` is the native attribute: the input and the chips' remove buttons leave the tab order.

<Keyboard>
  <Key keys="Tab">Moves to each chip's remove button, then to the input. A disabled field is skipped. Tabbing out of the field closes its menu. In the menu, Tab or Shift + Tab closes it and returns focus to the input.</Key>
  <Key keys="Arrow Down">In the input, opens the menu; when it's open, moves into the first row. In the menu, moves to the next row, wrapping to the first.</Key>
  <Key keys="Arrow Up">In the menu, moves to the previous row, wrapping to the last.</Key>
  <Key keys="Home">In the menu, moves to the first row.</Key>
  <Key keys="End">In the menu, moves to the last row.</Key>
  <Key keys="Enter">In the input, opens a closed menu. On a row, chooses it.</Key>
  <Key keys="Space">In the input, opens a closed menu when nothing's typed. On a row, chooses it.</Key>
  <Key keys="Backspace">In an empty multi-select input, removes the last chosen value.</Key>
  <Key keys="Escape">Closes the menu and clears the typed text. From inside the menu, focus returns to the input.</Key>
</Keyboard>

</Section>
