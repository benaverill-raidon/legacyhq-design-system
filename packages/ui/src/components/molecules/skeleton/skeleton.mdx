<UseFor>

- Sketching a whole loading layout, by putting several skeletons together.

</UseFor>
<UseInstead>

</UseInstead>

<Section title="Variants">

`appearance` sets how visible the fill is. `subtle`, the default, is lighter, for dense layouts
where real content sits nearby. `default` is stronger, for a loading state that fills the screen.
`shape` sets the corners: `rectangle`, the default, has small rounded corners for text lines,
cards, and images; `round` is fully rounded, for an avatar. `circle`, the earlier name for `round`,
is still accepted.

<Example of={SkeletonStories.Variants} />

<Subsection title="Sizing">

Skeleton has no size scale. By default it fills its container's width and is one text line tall
(20px). Set its size with `style` or `className` to match the content it stands in for, and give a
`round` skeleton an equal width and height, or it becomes a pill.

<Example of={SkeletonStories.Composition} caption="Text lines, a list row with an avatar, a card, and a labelled skeleton." />

</Subsection>

</Section>

<Section title="Behavior">

<Subsection title="Pulse">

Every skeleton pulses, fading to half opacity and back every 1.5s with the `pulse-loop` motion
recipe, whatever its appearance. With reduced motion it holds still at full opacity.

</Subsection>

<Subsection title="Decorative or announced">

Without `label`, a skeleton is hidden from assistive technology, for a region that already says
it's loading, such as a heading or a status message nearby. With `label`, it becomes a polite
status region that holds the label as visually hidden text. When skeletons are the only sign that a
region is loading, label one of them, not each.

</Subsection>

</Section>

<Section title="Accessibility">

- Skeleton renders a `div`. It isn't focusable and has no keyboard interaction.
- Without `label`, the `div` is `aria-hidden` and has no role.
- With `label`, the `div` gets `role="status"` and `aria-live="polite"`, and the label is inside it
  as visually hidden text.
- Skeleton sets `role`, `aria-live`, and `aria-hidden` itself, so values you pass for them are
  replaced.
- Reduced motion stops the pulse.

</Section>
