<Section title="Anatomy">

<Anatomy specimen={<TagGroup tags={labels(6)} maxVisible={3} />}>
  <Part name="root" target={tagGroupStyles.root}>A `div` that lays the tags out in a row, 8px apart in both directions, wrapping as it fills. It has no padding, border, or fill.</Part>
  <Part name="visible tags" target={tagStyles.root}>The first `maxVisible` tags, each a real Tag. All of them show when `maxVisible` is unset.</Part>
  <Part name="overflow tag" target={tagStyles.root} nth={4}>Only when tags are hidden: a Tag that's a button, reading `+3 more` by default. It opens the overflow panel.</Part>
  <Part name="overflow panel">Shown only while open: a Dropdown Menu listing each hidden tag by its text, with its icon.</Part>

<Section title="Variants">

<Subsection title="Sizes">

`sm` (24px), the default, and `md` (32px). One `size` sets every tag and the overflow tag; there's no
size per tag. Tag Group defaults to `sm`, where a single Tag defaults to `md`.

<Example of={TagGroupStories.Sizes} />

</Subsection>

<Subsection title="Alignment">

`alignment` sets where the overflow tag sits: after the visible tags with `left`, the default, or
before them with `right`. It doesn't change which tags show or the order they're in, and the menu
always opens below the overflow tag, aligned to its left edge. In Figma, the component is named
`tab-group`.

<Example of={TagGroupStories.Overflow} />

</Subsection>

</Section>

<Section title="Behavior">

<Subsection title="Wrapping and overflow">

With no `maxVisible`, every tag shows and the row wraps onto new lines, with no overflow tag. Once
there are more tags than `maxVisible`, the first `maxVisible` show and the rest move into the
overflow menu, in order. `maxVisible={0}` leaves only the overflow tag.

<Example of={TagGroupStories.Wrapping} caption="Eight tags in a 360px container, with no maxVisible." />

</Subsection>

<Subsection title="Choosing a hidden tag">

The overflow tag opens and closes the menu. Each row shows the tag's text and its `elemBefore` icon;
a tag with `isDisabled` is a disabled row. The tag's tone, link, and remove button don't carry into
the menu.

Choosing a row calls `onOverflowTagSelect` with that tag and the event. The menu then closes and
focus returns to the overflow tag. Tag Group doesn't follow the tag's `href` or call its `onRemove`:
do what the tag means from the callback. To keep the menu open, call `event.preventDefault()` in it.

<Example of={TagGroupStories.EdgeCases} caption="Choosing a hidden tag, and one tag under maxVisible." />

</Subsection>

<Subsection title="Each tag is a Tag">

Every prop on an item except `size`, `children`, and `isInteractive` goes to its Tag, and `label` is
its text. So a visible tag can link with `href`, show an icon with `elemBefore`, or be removed with
`isRemovable` and `onRemove`. Tag Group doesn't remove tags itself: take the tag out of `tags` in
`onRemove`.

<Example of={TagGroupStories.Content} caption="Linked records with tones and icons, and a removable tag." />

</Subsection>

</Section>

  caption="Follow a hidden tag's link from onOverflowTagSelect, which is the only thing a menu row calls."

<Section title="Accessibility">

- The root is a `div` with no role or name, and Tag Group adds nothing to the visible tags: each is a
  Tag, with its own link and remove button.
- The overflow tag is a native `button`. Its visible text, `+5 more` by default, is its accessible
  name. It gets `aria-haspopup="menu"`, `aria-expanded`, and `aria-controls` from Dropdown Menu.
- The menu has `role="menu"` and is named by `overflowMenuAriaLabel`, “5 more tags” by default.
  Translate it and `overflowLabel` with the rest of your interface. Each row is a `menuitem` named
  by the tag's text; its icon is hidden from assistive technology.
- Opening the menu moves focus to the first enabled row. Choosing a row, Escape, or Tab out of the
  menu closes it and returns focus to the overflow tag.
- Focus shows the shared Focus Ring on each link, remove button, and the overflow tag.

<Keyboard>
  <Key keys="Tab">Moves through the tags' links and remove buttons and the overflow tag, in the order they show. In the open menu, closes it and returns focus to the overflow tag.</Key>
  <Key keys="Enter">On the overflow tag, opens or closes the menu. On a row, chooses that tag, closes the menu, and returns focus to the overflow tag.</Key>
  <Key keys="Space">The same as Enter, except on a link.</Key>
  <Key keys="Arrow Down">In the menu, moves to the next enabled row, wrapping from the last to the first.</Key>
  <Key keys="Arrow Up">In the menu, moves to the previous enabled row, wrapping from the first to the last.</Key>
  <Key keys="Home">In the menu, moves to the first enabled row.</Key>
  <Key keys="End">In the menu, moves to the last enabled row.</Key>
  <Key keys="Escape">Closes the menu and returns focus to the overflow tag.</Key>
</Keyboard>

</Section>

<Section title="API">

<PropsTable of={TagGroupStories} />

Each item in `tags` takes every Tag prop except `size`, `children`, and `isInteractive`, plus a
required `id` that must be unique in the group and a `label`, the tag's text. Tag Group doesn't pass
other attributes to its root.
