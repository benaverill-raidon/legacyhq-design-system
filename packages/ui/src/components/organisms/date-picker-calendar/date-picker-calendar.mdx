# Date Picker Calendar

Date Picker Calendar is the month-grid panel for choosing a single date. It is the content that fills
the popup surface of the upcoming Date Picker and Date/Time Picker, and can be used anywhere a date
needs to be picked from a calendar.

<Canvas of={DatePickerCalendarStories.Playground} />

## When to use

- Inside a date field's popup, to pick a day.
- Any inline "pick a date" surface (a scheduling panel, a filter).

## When not to use

- **For a full field + popup** - that is the Date Picker (which wraps this calendar); use it when you
  need an input.
- **For picking a time** - use the Time Picker; Date/Time Picker combines both.
- **For a small set of preset dates** - a Select or Radio group may be simpler.

## Anatomy

1. **Month header** - previous-year (`«`), previous-month (`‹`), the month + year title, next-month
   (`›`), and next-year (`»`) controls. The four controls are Icon Buttons (`subtle`, `xs`, square).
2. **Weekday header** - a `columnheader` per weekday, starting on `weekStartsOn`.
3. **Day grid** - a `role="grid"` of six weeks; each day is a button in a `gridcell`. Out-of-month
   days are shown for context but muted; today is underlined; the selected day fills the selected
   surface.

## Usage guidance

### Selection

Uncontrolled, the calendar owns the selection (`defaultValue`) and the displayed month
(`defaultMonth`). For controlled usage, pass `value` + `onChange` (see the Controlled story). The
calendar is **transparent** - the surrounding popup provides the surface and elevation.

### Restricting dates

<Canvas of={DatePickerCalendarStories.MinMax} />

`min` / `max` bound the selectable range (inclusive); out-of-range days are disabled and the
year/month nav is blocked once the whole target month is out of range. `isDateDisabled(date)` disables
individual dates:

<Canvas of={DatePickerCalendarStories.DisabledWeekends} />

### Week start

<Canvas of={DatePickerCalendarStories.WeekStartsMonday} />

`weekStartsOn` (0 = Sunday, the default; 1 = Monday, ...) sets the first column. Month, year, and
weekday names come from `locale`.

### Accessibility

The grid is a `role="grid"` labelled by the month title (`aria-live` so month changes are announced).
Days use a roving tabindex - only one day is in the tab order. Arrow keys move by day and week,
**Home**/**End** jump to the start/end of the week, **PageUp**/**PageDown** change month
(with **Shift**, year), and **Enter**/**Space** select. Focus uses the shared Focus Ring. Today is
`aria-current="date"`; the selected day's cell is `aria-selected`; disabled days are `aria-disabled`.
