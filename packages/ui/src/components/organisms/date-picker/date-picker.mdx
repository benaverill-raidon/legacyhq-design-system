# Date Picker

Date Picker is a date field that opens the Date Picker Calendar in a popup. The read-only field shows
the selected date and a calendar icon; the calendar does the picking.

<Canvas of={DatePickerStories.Playground} />

## When to use

- A single-date field in a form or filter.

## When not to use

- **An always-visible calendar** - use Date Picker Calendar directly.
- **Picking a time** - use the Time Picker (Date/Time Picker combines both).
- **A small set of preset dates** - a Select may be simpler.

## Anatomy

1. **Field** - a read-only Text Field showing the formatted date with a trailing calendar icon; it is
   the disclosure control (`aria-haspopup="dialog"`).
2. **Popup** - a `role="dialog"` panel anchored to the field, providing the surface.
3. **Calendar** - the Date Picker Calendar inside the popup.

## Usage guidance

### Sizes and contexts

<Canvas of={DatePickerStories.Sizes} />

`size` (`sm`/`md`/`lg`) sets the field height. `context` maps to the Text Field appearance:

<Canvas of={DatePickerStories.Contexts} />

`default` is a bordered field; `inline` is borderless (subtle). The open state pins the field's focus
treatment - a border for `default`, an underline for `inline`.

### States

<Canvas of={DatePickerStories.States} />

Empty shows the `placeholder`; `disabled` and `invalid` map to the Text Field states.

### Restricting dates

<Canvas of={DatePickerStories.WithConstraints} />

`min` / `max`, `isDateDisabled`, `weekStartsOn`, `today`, and `locale` pass through to the calendar.

### Controlled

<Canvas of={DatePickerStories.Controlled} />

Pass `value` + `onChange` (and optionally `open` + `onOpenChange`) to control the picker.

### Accessibility

The field carries `aria-haspopup="dialog"` and, while open, `aria-expanded` + `aria-controls`
(managed by Popup) pointing at the dialog panel. Opening moves focus into the calendar grid; Escape or
selecting a day closes the popup and returns focus to the field; outside clicks dismiss without moving
focus. The calendar provides its own grid keyboard model. The field is read-only in this version -
pick via the calendar (typing a date directly is a future addition).
