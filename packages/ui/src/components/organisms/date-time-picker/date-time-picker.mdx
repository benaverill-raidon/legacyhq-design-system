# Date/Time Picker

Date/Time Picker combines a Date Picker and a Time Picker into one control - a date half on the left
and a time half on the right - over a single `Date` value.

<Canvas of={DateTimePickerStories.Playground} />

## When to use

- Capturing a specific moment: a date **and** a time (a meeting start, a deadline, a reminder).

## When not to use

- **Only a date** - use the Date Picker.
- **Only a time** - use the Time Picker.

## Anatomy

1. **Date half** - a Date Picker (calendar popup) showing the date part.
2. **Divider** - the two field frames collapse into a single shared border between the halves.
3. **Time half** - a Time Picker (hours / minutes / AM-PM popup) showing the time part.

The two halves read as one field: a single rounded outline with squared inner corners and a divider.
Each half keeps its own popup, states, and keyboard model.

## Usage guidance

### Sizes and contexts

<Canvas of={DateTimePickerStories.Sizes} />

`size` (`sm`/`md`/`lg`) and `context` (`default` bordered / `inline` borderless) pass through to both
halves so they stay in step.

<Canvas of={DateTimePickerStories.Contexts} />

### One shared value

<Canvas of={DateTimePickerStories.Controlled} />

Both halves are driven by a single `Date`. Picking a **date** keeps the current time; confirming a
**time** keeps the current date. `onChange` fires with the combined `Date` whenever either half
changes. Date constraints (`min`, `max`, `isDateDisabled`, `weekStartsOn`) go to the calendar;
`minuteStep` goes to the time selector.

### Accessibility

The control is a `role="group"`; give it an `aria-label` (or `aria-labelledby`). Each half is an
independent field with its own accessible name (`dateLabel` / `timeLabel`, defaulting to `Date` /
`Time`), popup, and keyboard model - see the Date Picker and Time Picker docs.
