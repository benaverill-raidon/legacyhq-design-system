<Section title="Variants">

`appearance` sets the background, and nothing else: the content is the same in both. `inherited`,
the default, is transparent, so it takes on the card, panel, or table it sits in. `informative` fills
a sunken panel, for an empty state that stands on its own. The panel has no border or rounded
corners. `type`, the earlier name for `appearance` and still Figma's name for it, is still accepted.

</Section>

<Subsection title="Content">

Only the description is required. Leave out the illustration, the heading, or the actions for a
lighter empty state; a description alone is enough for a small space.

<Example of={EmptyStateStories.Content} caption="Every part, no illustration, a description alone, and no actions." />

<Subsection title="Width and long text">

Empty State is as wide as its container, and has no maximum width for its text. Everything is
centered, so a long heading or description wraps onto centered lines that run the full width. Keep
the heading to a few words and the description to a sentence or two.

<Section title="Accessibility">

- Empty State renders a `div` with no role. It isn't focusable and isn't a live region; its actions
  are reached with Tab, in page order.
- The heading is a real heading element, `h2` by default, so it's announced as a heading and listed
  among the page's headings. Set `headingLevel` to fit the page's outline, usually one level below
  the heading of the section the Empty State is in. The level doesn't change how it looks. Pass text
  or inline content as `heading`, not another heading element.
- Empty State doesn't hide the illustration from assistive technology. Mark a decorative one as
  decorative: Icon Tile is hidden by default, and an image needs `alt=""`.
- When an Empty State replaces results, for example after a search, it isn't announced. Announce the
  change from a region that stays on the page, such as a status message with the result count.

</Section>
