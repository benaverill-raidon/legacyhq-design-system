<Section title="Variants">

<Subsection title="Width">

`size` sets the Menu's width only: `sm` (192px, the default), `md` (240px), or `lg` (288px). Rows
are as tall as their content at every size, and a long label is cut off with an ellipsis.
`fullWidth` fills the container instead, for a panel sized to its trigger, such as Select's.

<Example of={MenuStories.Sizes} caption="The same rows at each width." />

</Subsection>

</Section>

<Section title="Behavior">

<Subsection title="Rows from data">

Menu takes its rows as data, `sections` of `items`, not as child components. Each item is one row:
a label, an optional description, optional slots before and after, and an `onSelect`. The slots
are hidden from assistive technology and must never hold a control, because the row is already a
button. An icon in a slot needs no color: it takes the row's text color, so it follows the row
through selected and disabled.

<Example of={MenuStories.Content} caption="Descriptions and a disabled row, Avatar rows, checkbox-style and radio-style choices, and two sections." />

</Subsection>

<Subsection title="Selection">

Selection is per row. Leave `selected` and `selectionType` off for a plain action. Set
`selectionType` to `checkbox` or `radio` with `selected` for an option that's checked or chosen:
the row is announced as checked or not. Menu doesn't keep radio rows exclusive, so set `selected` on
exactly one. `selected` alone changes only the look, with a tinted fill, the selected text color,
and a 2px bar on the left edge.

For checkbox-style and radio-style rows, put the matching icon in `leadingElement`:
`CheckboxFillIcon` and `CheckboxEmptyIcon`, or `RadioCheckedIcon` and `RadioUncheckedIcon`, with
`color="subtle"` on the unchecked one. The checked icon takes the selected color from the row.

</Subsection>

<Subsection title="Search">

`showSearch`, on by default, puts a search field above the sections and focuses it when the Menu
mounts, which in a Dropdown Menu means every time it opens. Menu filters, but it keeps no search
state: pass `searchValue` and `onSearchChange`, as the example at the top does. Rows stay when their
label or description contains the text, ignoring case. Only string labels and descriptions can be
matched, so a row with neither always stays. Sections left with no rows are hidden, and when nothing
is left, `emptyMessage` shows instead. The clear button appears once there's text, and sets the
search back to empty.

Turn the field off with `showSearch={false}` when the list is short, or when the search lives
elsewhere, as Select's does.

</Subsection>

<Subsection title="Loading and long lists">

`loading` replaces the sections with a loading row, a Spinner and `loadingLabel`, while the search
field stays usable. `maxHeight` caps the height of the sections, and with `showScrollbar`, on by
default, they scroll past it; with `showScrollbar` off, rows past `maxHeight` are cut off.

</Subsection>

<Subsection title="Menu doesn't close">

Menu has no open state and doesn't know whether it's in a Dropdown Menu, a card, or a sidebar. It
only calls `onSelect`. To close a containing Dropdown Menu after a choice, set its `open` to false
from the item's `onSelect`.

</Subsection>

<Section title="Accessibility">

- Menu renders a `div` holding the search field and a `div` with `role="menu"`. Name the menu with
  `aria-label` or `aria-labelledby`: it has no default name.
- Each row is a native `button` with the role `menuitem`, or `menuitemcheckbox` or `menuitemradio`
  with `aria-checked` when `selectionType` is set. `selected` without a `selectionType` isn't
  announced.
- A row's text is its accessible name. The slots before and after it, and a heading's icon, are
  hidden from assistive technology, so an icon can't carry meaning a row's text doesn't.
- Section headings are plain text in the menu, not labels for their rows. Dividers have
  `role="separator"`.
- One row at a time is in the tab order: the last one focused, or else the first enabled one. The
  arrow keys move focus between rows. Disabled rows can't be focused and are skipped. Rows use the
  shared Focus Ring, drawn inside the row.
- The search field sits outside the menu role. It's named by `searchPlaceholder`, or "Search", and
  takes focus when the Menu mounts. The arrow keys don't move from it into the rows; Tab does.
- While `loading`, the loading row has `role="status"`, so `loadingLabel` is announced, and there's
  no menu role until it finishes. The empty message is plain text and isn't announced on its own.

<Keyboard>
  <Key keys="Tab">From the search field, moves to the clear button if it's shown, then to the rows' tab stop. From a row, leaves the menu.</Key>
  <Key keys="Arrow Down">Moves to the next enabled row, wrapping from the last to the first.</Key>
  <Key keys="Arrow Up">Moves to the previous enabled row, wrapping from the first to the last.</Key>
  <Key keys="Home">Moves to the first enabled row.</Key>
  <Key keys="End">Moves to the last enabled row.</Key>
  <Key keys="Enter">Activates the focused row and calls its `onSelect`.</Key>
  <Key keys="Space">Activates the focused row and calls its `onSelect`.</Key>
</Keyboard>

Menu doesn't handle Escape. In a Dropdown Menu, Escape closes the panel.

</Section>

<PropsTable of={MenuStories} />

<Subsection title="Sections and items">

Each entry in `sections` is a `MenuSection`:

- `id` (required): unique within the Menu.
- `items` (required): the section's rows, in order.
- `heading`: text above the rows. It isn't a label for assistive technology.
- `headingLeadingElement`: an icon before the heading, hidden from assistive technology.

Each entry in `items` is a `MenuItem`:

- `id` (required): unique within the Menu. It tracks which row is the tab stop.
- `label` (required): the row's text and accessible name. Search matches it only when it's a string.
- `description`: a second, smaller line under the label. Search matches it only when it's a string.
- `leadingElement`: a 24px slot before the text, for an icon or an Avatar. Hidden from assistive technology; never a control.
- `titleLeadingElement`: a small icon right before the label, on its line. Rare.
- `trailingElement`: a 24px slot after the text, for a chevron, a count, or a shortcut hint. Hidden from assistive technology.
- `selected`: shows the row as selected. Announced only with `selectionType`.
- `selectionType`: `checkbox` or `radio`. Sets the row's role and `aria-checked`.
- `disabled`: the native attribute. The row can't be focused or chosen.
- `onSelect`: called on click, Enter, or Space.

</Subsection>
