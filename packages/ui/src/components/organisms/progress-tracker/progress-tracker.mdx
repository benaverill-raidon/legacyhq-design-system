<Section title="Behavior">

<Subsection title="Progress and going back">

`currentStep` counts from 1 and is clamped to the number of steps. The bar fills to
`currentStep / steps.length`, so it ends where the current step's share of the width ends, and the
fill animates when it changes. The current step's name is in the selected color and marked
`aria-current="step"`. Steps before it are done: give them an `href` and their names become Links
back to them. The current step and the ones after it are never links, even with an `href`.

Visited-step links don't turn purple, and on hover they darken instead of underlining.

<Example of={ProgressTrackerStories.Progress} caption="The first step, a flow in progress, and the last step." />

</Subsection>

<Subsection title="Disabled">

`disabled` greys the fill and the bar's outline and mutes every step name, and no step is a link. A
single step can be disabled with the step's own `disabled`: its name is muted and never a link,
even after it's done. Neither sets `aria-disabled`.

<Example of={ProgressTrackerStories.Disabled} />

</Subsection>

<Section title="Accessibility">

- The root is a `nav` named by `aria-label`, "Progress" by default, or by `aria-labelledby`, which
  replaces it. Name it for the flow.
- The steps are an ordered list, so assistive technology announces how many there are. The current
  step's name has `aria-current="step"`.
- The bar is hidden from assistive technology: the list and `aria-current` carry the position.
- Each visited step with an `href` is a Link: announced as a link, in the tab order, with the
  shared Focus Ring. Every other step is plain text and isn't focusable.
- A disabled tracker or step sets no `aria-disabled`; its names are text, so nothing in it is
  focusable.

<Keyboard>
  <Key keys="Tab">Moves focus to the next visited step that's a link. Other steps are skipped.</Key>
  <Key keys="Enter">Follows the focused step's link.</Key>
</Keyboard>

<Subsection title="Step">

Each entry in `steps` takes:

- `label`, required: the step's name.
- `href`: a link back to the step, used only once the step is done.
- `target`: passed to the Link. `_blank` adds Link's new-tab icon and hidden text.
- `onClick`: called when the step's link is activated, so only a step that's a link calls it.
- `disabled`: mutes the step's name and keeps it from ever being a link.

</Subsection>
