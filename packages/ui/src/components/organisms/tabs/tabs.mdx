<Section title="Variants">

`appearance` sets the style. `line`, the default, is a row of tabs over a line, with the selected tab
underlined in the selected color: the everyday choice. `contained` puts the tabs in a raised,
rounded container and fills the selected one as a pill, for a denser surface such as a card. In both,
unselected tabs use the subtle color and darken on hover. `showBorder` turns off the line under a
`line` tab list or the border of a `contained` one; it's on by default for both.

</Section>

<Section title="Behavior">

<Subsection title="Selection">

Tabs manages the selection on its own, starting from `defaultValue` or the first enabled tab. To
control it, pass `value` and update it from `onValueChange`, which is called with a tab's `value`
whenever it's clicked or reached with the keyboard. Selection follows focus: moving to a tab with the
arrow keys selects it, with no extra Enter.

<Example of={TabsStories.Controlled} caption="Controlled: the parent holds the value and shows it above the tabs." />

</Subsection>

<Subsection title="Panels">

Give Tabs a `TabPanel` for each tab `value`, as its children, and it wires each panel to its tab
and shows only the selected one. A tab points at its panel with `aria-controls` only while that
`TabPanel` is rendered, so a tab bar used alone points at nothing. A panel's content is rendered only while its tab is selected, so
state inside it resets when you switch away. Panels are optional: render the tab bar alone and
switch the content yourself from `value`.

</Subsection>

<Subsection title="Disabled tabs">

A tab with `disabled` uses the native attribute: it's muted, can't be clicked, and the arrow keys
skip it. `showBorder={false}` is shown here too.

<Example of={TabsStories.States} />

</Subsection>

</Section>

<Section title="Accessibility">

- The tab list has `role="tablist"` and `aria-orientation="horizontal"`. `aria-label` or
  `aria-labelledby` names it; both go on the tab list, not the root. Always set one.
- Each tab is a native `button` with `role="tab"` and `aria-selected`. A tab whose `TabPanel` is
  rendered also has `aria-controls` set to the panel's id; without a panel, it has none.
- Only the selected tab is in the tab order; the arrow keys move between tabs. If `value` or
  `defaultValue` matches no enabled tab, the first enabled tab takes its place in the tab order.
  Disabled tabs use the native `disabled` attribute and are skipped.
- Each `TabPanel` has `role="tabpanel"`, is labelled by its tab, and has `tabindex="0"`, so Tab
  moves from the tab list to the panel. Unselected panels are `hidden`.
- Tabs show the shared Focus Ring.

<Keyboard>
  <Key keys="Tab">Moves focus to the selected tab, then out of the tab list to the panel.</Key>
  <Key keys="Arrow Right">Moves to and selects the next enabled tab, wrapping from the last to the first.</Key>
  <Key keys="Arrow Down">Does the same as Arrow Right.</Key>
  <Key keys="Arrow Left">Moves to and selects the previous enabled tab, wrapping from the first to the last.</Key>
  <Key keys="Arrow Up">Does the same as Arrow Left.</Key>
  <Key keys="Home">Moves to and selects the first enabled tab.</Key>
  <Key keys="End">Moves to and selects the last enabled tab.</Key>
  <Key keys="Enter">Selects the focused tab, which the arrow keys have already selected.</Key>
  <Key keys="Space">Selects the focused tab, which the arrow keys have already selected.</Key>
</Keyboard>

</Section>
