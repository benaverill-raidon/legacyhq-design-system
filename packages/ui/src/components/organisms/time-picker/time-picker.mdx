# Time Picker

Time Picker is a time field that opens a three-column time selector in a popup: hours, minutes, and
AM/PM. The read-only field shows the selected time and a clock icon; the columns do the picking, and a
Confirm commits the choice.

<Canvas of={TimePickerStories.Playground} />

## When to use

- A single time-of-day field in a form or filter.

## When not to use

- **Picking a date** - use the Date Picker (Date/Time Picker combines both).
- **A duration or a countdown** - this selects a time of day.

## Anatomy

1. **Field** - a read-only Text Field showing the formatted time with a trailing clock icon; it is the
   disclosure control (`aria-haspopup="dialog"`).
2. **Popup** - a `role="dialog"` panel anchored to the field.
3. **Columns** - three scrollable listboxes (hours, minutes, AM/PM); the selected option in each is
   highlighted.
4. **Footer** - Cancel and Confirm buttons. Column changes are staged and previewed live in the
   field; **Confirm or an outside click** commits them, while **Cancel or Escape** discards them.

## Usage guidance

### Sizes and contexts

<Canvas of={TimePickerStories.Sizes} />

`size` (`sm`/`md`/`lg`) sets the field height. `context` maps to the Text Field appearance:

<Canvas of={TimePickerStories.Contexts} />

`default` is a bordered field; `inline` is borderless (subtle). The open state pins the field's focus
treatment - a border for `default`, an underline for `inline`.

### States

<Canvas of={TimePickerStories.States} />

Empty shows the `placeholder`; `disabled` and `invalid` map to the Text Field states.

### Minute step

<Canvas of={TimePickerStories.MinuteStep} />

`minuteStep` (default `5`) sets the minute increment.

### Controlled

<Canvas of={TimePickerStories.Controlled} />

Pass `value` + `onChange` (and optionally `open` + `onOpenChange`). The value is carried on a `Date`
(only hours and minutes are used), so it composes cleanly with the Date Picker in a Date/Time Picker.

### Accessibility

The field carries `aria-haspopup="dialog"` and, while open, `aria-expanded` + `aria-controls`
(managed by Popup) pointing at the dialog panel. Each column is a `role="listbox"` of `role="option"`
buttons with a roving tabindex; Arrow Up/Down (and Home/End) move within a column, Tab moves between
columns, and Escape (or Cancel) discards and closes. While open, the field previews the staged
selection live; **Confirm or an outside click commits** it, and **Cancel or Escape discards** it.
