  Focus Ring is the keyboard focus outline every interactive component shares: 2px in the focus
  color, outside the control, shown only when focus comes from the keyboard. Components compose it,
  and you reach for it when you build a control of your own. These are shown focused.

<Section title="When to use">

<Usage>
<UseFor>

- Every element a new component renders that can take focus: a `button`, a link, an `input`, or an element with `tabIndex`.
- A custom control in product code, by wrapping its one focusable element in `<FocusRing>`.
- Instead of any one-off `:focus-visible` outline or shadow.

</UseFor>
<UseInstead>

- **A system component:** it already shows the ring, so don't wrap it. See <DocLink to="Components/Actions/Button" />.
- **A text field's focus:** <DocLink to="Components/Forms/Text Field" /> and the other fields turn their border the focus color instead.
- **Hover, selected, or error states:** each component's own styles. The ring means focus and nothing else.
- **Making an element focusable:** use a native control, or `tabIndex`. Focus Ring only draws.

</UseInstead>
</Usage>

</Section>

<Section title="Behavior">

<Subsection title="Keyboard focus only">

The ring shows on `:focus-visible`: when someone moves focus with the keyboard, or when the browser
otherwise decides focus should show, as it does in a text input. Clicking a button with a mouse
doesn't show it. It's an outline, so it takes no space and doesn't move anything around it, and it
follows the element's corner radius.

<Example of={FocusRingStories.Examples} caption="Button, Checkbox, and Switch, in light and dark themes. Press Tab to move through them." />

</Subsection>

<Subsection title="Two ways to apply it">

Components compose the classes onto their own element with `focusRingClassNames`, next to their
own classes. Every system component that shows the ring does it this way.

<CodeSample
  code={`import { focusRingClassNames } from '../../primitives/focus-ring';

<button
    className={mergeClassNames(
        styles.root,
        focusRingClassNames.focusRing,
        focusRingClassNames.focusRingDefault,
    )}
/>`}
/>

In product code, wrap one focusable element in `FocusRing`. It clones the element and adds the
same classes to its `className`, after the element's own.

<CodeSample
  code={`<FocusRing>
    <a href="/matters/42/history">Matter history</a>
</FocusRing>`}
/>

</Subsection>

<Subsection title="Tuning it for a component">

The ring reads three custom properties: `--focus-ring-color`, `--focus-ring-width`, and
`--focus-ring-offset`, 2px by default. A component changes its ring by setting them on its own root
class, never by writing a new outline. Button, Icon Button, and Tag set the offset to
`--spacing-xxs`; Checkbox and Radio set a negative one so the ring circles the box, not the larger
area you can click; Menu rows set a negative one so it's drawn inside the row. A component that
draws the ring on another element, such as Slider's thumb, reads the same properties in its own
outline.

<CodeSample
  code={`.root {
    --focus-ring-offset: var(--spacing-xxs);
}`}
/>

</Subsection>

<Subsection title="A pinned focus state">

`data-force-state="focus"` on the element shows the ring without focus, for documentation and
visual tests, as on this page. It isn't for product code.

</Subsection>

<Section title="Do and don't">

<Guidelines>
<Do
  caption="Compose focusRingClassNames on the element that takes focus."
  code={`className={mergeClassNames(styles.root, focusRingClassNames.focusRing, focusRingClassNames.focusRingDefault)}`}
>
  <Button data-force-state="focus">Save changes</Button>
</Do>
<Dont
  caption="Write a new focus style in a component's stylesheet. It drifts from every other control."
  code={`.myControl:focus-visible {
    outline: 2px solid blue;
}`}
/>
<Do
  caption="Wrap the one focusable element."
  code={`<FocusRing>
    <a href="/matters/42/history">Matter history</a>
</FocusRing>`}
>
  <FocusRing>
    <a href="#" data-force-state="focus">Matter history</a>
  </FocusRing>
</Do>
<Dont
  caption="Wrap an element that can't take focus. Nothing shows, because Focus Ring doesn't make it focusable."
  code={`<FocusRing>
    <div onClick={open}>Matter history</div>
</FocusRing>`}
/>
<Do
  caption="Set --focus-ring-offset on the component's own class to move the ring, as Checkbox does to circle the box."
  code={`.input {
    --focus-ring-offset: calc((var(--size-choice-target) - var(--size-choice-indicator)) / -2);
}`}
>
  <Checkbox label="Notify the client" data-force-state="focus" />
</Do>
<Dont
  caption="Override the outline itself to move it. The color and width stop following the shared ring."
  code={`.root:focus-visible {
    outline-offset: -2px;
}`}
/>
</Guidelines>

</Section>

<Section title="Accessibility">

- Focus Ring adds no element, role, or name, and it doesn't make anything focusable: the element
  keeps its own semantics.
- Every interactive component shows the same ring, so keyboard users learn one signal for where
  focus is.
- It's an outline, not a shadow, so it stays visible in Windows high contrast mode.
- `disabled` removes the ring and the browser's own outline. Use it only on a control that can't
  take focus; a focusable control with no focus indicator fails keyboard users.

</Section>
