<Section title="When to use">

<Usage>
<UseFor>

- The application header, usually as the link back to home.
- Sign-in and other branded screens.
- A collapsed navigation rail, with `type="mark"`.

</UseFor>
<UseInstead>

- **An icon in the interface:** <DocLink to="Foundations/Icons" />. The mark isn't an icon.
- **The product name in running text:** plain text. Logo is artwork, not a word in a sentence.
- **Another organization's logo:** an image of it. Logo draws only LegacyHQ's artwork.

</UseInstead>
</Usage>

</Section>

<Section title="Anatomy">

<Anatomy specimen={<Logo size="lg" />}>
  <Part name="root" target={logoStyles.logo}>A `span` that sets the height from `size` and holds the artwork. It carries the `title` attribute, and `aria-hidden` when the logo is decorative.</Part>
  <Part name="artwork" target={logoStyles.svg}>The approved SVG for the `type`, drawn inline at the root's height. It carries the role and the accessible name.</Part>
</Anatomy>

<Section title="Variants">

<Subsection title="Type">

`full`, the default, is the mark and the wordmark together: use it wherever there's room, since
it's the most recognizable. `mark` is the symbol alone, for a tight space such as a collapsed
navigation rail. `wordmark` is the name alone.

<Example of={LogoStories.Variants} caption="Each type at each size, from xxs to lg." />

</Subsection>

<Subsection title="Size">

`size` sets the height: `xxs` 16px, `xs` 24px, `sm` 32px, `md` 40px (the default), and `lg` 48px.
The width follows the artwork's proportions, so a size never stretches it. Pick a size from the
scale rather than scaling the logo with CSS.

</Subsection>

</Section>

<Section title="Behavior">

<Subsection title="Color and themes">

The mark is drawn in the brand primary color and the wordmark in the default text color, both read
from tokens inside the artwork, so the logo follows the light and dark themes on its own. There's
no prop to recolor it, and it shouldn't be recolored.

<Example of={LogoStories.Examples} caption="In a header link, a compact navigation rail, and on light and dark surfaces." />

</Subsection>

</Section>

<Section title="Accessibility">

- By default the logo is an image with a name: the artwork has `role="img"` and an `aria-label`
  from `ariaLabel`, then `title`, then "LegacyHQ". It's informative by default, unlike Icon, because
  a logo is often all there is in a link back to home.
- `decorative` puts `aria-hidden` on the root and the artwork and drops the role. Use it when the
  text beside the logo already names the same thing, so it isn't read twice, but never on a link's
  only content.
- `title` also shows as the browser's tooltip on hover; it's set on the root even when the logo is
  decorative.
- The artwork can't take focus, and Logo isn't interactive. To link it, put it in a
  <DocLink to="Components/Navigation/Link" />, which takes the focus and the Focus Ring.

</Section>
