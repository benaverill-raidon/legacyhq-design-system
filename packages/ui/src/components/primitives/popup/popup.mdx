export const MatterDetails = ({ alignment = 'bottomLeft' }) => {
  const [open, setOpen] = React.useState(false);
  const triggerRef = React.useRef(null);
  const linkRef = React.useRef(null);
  React.useEffect(() => {
    if (!open) return undefined;
    // The panel is hidden until it's positioned, so focus waits a frame.
    const frame = window.requestAnimationFrame(() => linkRef.current?.focus());
    return () => window.cancelAnimationFrame(frame);
  }, [open]);
  const handleOpenChange = (next) => {
    setOpen(next);
    if (!next) triggerRef.current?.focus();
  };
  return (
    <Popup
      open={open}
      onOpenChange={handleOpenChange}
      alignment={alignment}
      content={
        <div role="dialog" aria-label="Matter details">
          <KeyValueList>
            <KeyValuePair label="Owner" value="Dana Reyes" size="sm" />
            <KeyValuePair label="Opened" value="12 March 2026" size="sm" />
          </KeyValueList>
          <Link ref={linkRef} href="#">Open matter</Link>
        </div>
      }
    >
      <Button ref={triggerRef} iconAfter={<CaretDownIcon />} onClick={() => setOpen((current) => !current)}>
        Matter details
      </Button>
    </Popup>
  );
};

  Popup is the floating panel underneath Tooltip, Dropdown Menu, the pickers, and Inline Message. It

<Section title="Variants">

<Subsection title="Alignment">

`alignment` sets which side of the trigger the panel opens on, `top` or `bottom`, and which edge it
lines up with: `Left`, `Center`, or `Right`. The default is `topLeft`, as in Figma. It's a
preference: where the panel would overflow the viewport, Popup tries the same alignment on the other
side, then the rest, and uses the one that overflows least.

<Example of={PopupStories.Variants} caption="The six alignments, and the sm, md, and lg padding." />

</Subsection>

<Subsection title="Surface and padding">

By default the panel has Popup's surface: the raised surface color, a border, an 8px radius, and the
overlay shadow, with 16px of padding. `padding` sets just the padding, from `none` to `lg`; Dropdown
Menu and the pickers use `none` because their content has its own insets. `unstyled` leaves the
surface off entirely for a different look, as Tooltip does, and keeps the position and the fade.

</Subsection>

</Section>

<Section title="Behavior">

<Subsection title="Your state opens and closes it">

Popup never opens or closes itself, and it adds no click or hover handler to the trigger. Keep
`open` in your state, toggle it from the trigger, and pass `onOpenChange`: Popup calls it with
`false` on Escape and on a pointer press outside the trigger and the panel. Turn either off with
`closeOnEscape` or `closeOnOutsideClick` for content that should stay open until the trigger closes
it. While closed, only the trigger renders.

<Example of={PopupStories.EdgeCases} caption="Fallback near the viewport edge, the default dismissal, and dismissal turned off." />

</Subsection>

<Subsection title="Focus">

Popup doesn't move focus. The panel is added at the end of the page, so content in it doesn't come
after the trigger in the tab order. When the content is interactive, move focus into it on open and
back to the trigger on close, as the example at the top and Dropdown Menu do. Wait a frame before
moving focus in: the first time the panel opens, it stays hidden until it's positioned, and a
hidden element can't take focus.

<CodeSample
  code={`const [open, setOpen] = useState(false);
const triggerRef = useRef(null);
const linkRef = useRef(null);

useEffect(() => {
    if (!open) return undefined;
    const frame = requestAnimationFrame(() => linkRef.current?.focus());
    return () => cancelAnimationFrame(frame);
}, [open]);

function handleOpenChange(next) {
    setOpen(next);
    if (!next) triggerRef.current?.focus();
}

<Popup open={open} onOpenChange={handleOpenChange} content={…}>
    <Button ref={triggerRef} onClick={() => setOpen(!open)}>Matter details</Button>
</Popup>`}
/>

</Subsection>

<Subsection title="Position and width">

The panel sits 8px from the trigger (4px from a field in an editable Table cell) and stays at least
8px inside the viewport. It follows the trigger as the page scrolls or resizes, and hides while the
trigger is scrolled out of view, without changing `open`. It's as wide as its content;
`matchTriggerWidth` makes it as wide as the trigger instead, and `anchorRef` positions it against
another element, as the pickers do with their field frame.

The panel sits at z-index 1, below Modal Dialog and Toast Group, so a Popup opened from inside a
Modal Dialog shows behind it. That's a known issue.

</Subsection>

<Subsection title="Content">

Popup renders whatever you pass, and its panel has no role of its own. Pass the role of what you're
building, such as `menu` or `dialog`, and name it on your content, since the panel takes no label.

<Example of={PopupStories.Content} caption="A menu-shaped panel and a one-line message, the shapes Dropdown Menu and Inline Message use." />

</Subsection>

<Subsection title="Motion">

The panel fades in with `fade-quick` when it opens, and leaves at once when it closes. The fade is
off when the user prefers reduced motion.

</Subsection>

</Section>

  code={`<Popup open={open} content={…}>
    <Button onClick={() => setOpen(!open)}>Matter details</Button>
</Popup>`}
/>
<Do
  caption="Pass the focusable element itself as the trigger."
  code={`<Popup open={open} onOpenChange={setOpen} content={…}>
    <Button onClick={() => setOpen(!open)}>Matter details</Button>
</Popup>`}
>
  <MatterDetails />
</Do>
<Dont
  caption="Wrap the trigger in another element. The wrapper gets aria-expanded and the position, and the button doesn't."
  code={`<Popup open={open} onOpenChange={setOpen} content={…}>
    <span>
        <Button onClick={() => setOpen(!open)}>Matter details</Button>
    </span>
</Popup>`}
/>

    <Button>Save all</Button>

    <Button>Save all</Button>
  </Tooltip>
</Do>

<Section title="Accessibility">

- Popup adds no element around the trigger, which keeps its own role and name. It sets
  `aria-expanded` to `open` and, while open, `aria-controls` to the panel's id; while closed, the
  trigger keeps any `aria-controls` of its own. Set `manageTriggerAria={false}` when the trigger
  relates to the panel another way, as Tooltip does with `aria-describedby`.
- The panel is a `div` with no role unless you pass `role`. Give it the role of what you're building
  and name it on the content.
- Popup doesn't move or return focus. Because the panel is added at the end of the page, move focus
  into interactive content when it opens and back to the trigger when it closes.
- While open, Escape calls `onOpenChange(false)` wherever focus is, unless `closeOnEscape` is off.
- The fade is turned off when the user prefers reduced motion.

<Keyboard>
